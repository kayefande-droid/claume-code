# GODMODE - Senior Website Design Orchestrator

This skill provides advanced website design capabilities by orchestrating multiple AI-powered design tools and systems to create senior-level, professional websites that appear human-crafted.

## Overview

GodMode combines the power of:
- **ReactBits MCP Server** - Access to 135+ animated React components
- **UI/UX Pro Max** - 84 UI styles, 161 color palettes, 73 font pairings, 99 UX guidelines
- **Ultracode Workflows** - Multi-agent orchestration for complex tasks
- **All Available Design Skills** - Comprehensive design system access
- **MCP Servers** - Extended functionality through Model Context Protocol

## Usage

To activate GodMode website design capabilities, simply use the command:

```
/godmode [website description]
```

Or in conversation, mention "godmode" followed by your website requirements.

## Capabilities

When activated, GodMode will:

1. **Analyze Requirements** - Understand your website goals, target audience, and brand identity
2. **Select Optimal Tech Stack** - Recommend and configure appropriate frameworks (React, Vue, Svelte, etc.)
3. **Curate Design System** - Select perfect color schemes, typography, and UI patterns from available libraries
4. **Integrate Animations** - Add smooth, professional animations using ReactBits components
5. **Embed Multimedia** - Strategically place videos and interactive elements
6. **Ensure Responsiveness** - Create mobile-friendly, adaptive designs
7. **Optimize Performance** - Balance visual richness with loading speed
8. **Apply Human-Crafted Aesthetics** - Ensure the final product doesn't appear AI-generated

## Workflow Process

When you invoke GodMode with a website request, it will:

### Phase 1: Discovery & Planning
- Analyze your requirements for purpose, audience, and goals
- Research similar successful websites for inspiration (conceptually)
- Define site architecture and user journey

### Phase 2: Design Foundation
- Select optimal color palette from 161+ options using UI/UX Pro Max
- Choose perfect typography pairings from 73+ font combinations
- Establish layout grids and spacing systems
- Define component library and UI patterns

### Phase 3: Component Selection & Customization
- Browse ReactBits MCP server for relevant animated components
- Select and customize interactive elements (buttons, forms, navs, etc.)
- Integrate video players and media elements where appropriate
- Apply micro-interactions and motion design principles

### Phase 4: Assembly & Refinement
- Construct page layouts using selected components
- Apply responsive breakpoints and mobile optimizations
- Fine-tune animations for performance and smoothness
- Ensure accessibility compliance (WCAG 2.1 AA)
- Optimize asset loading and bundle size

### Phase 5: Quality Assurance
- Cross-browser compatibility checks
- Performance auditing and optimization
- Accessibility validation
- Design consistency review
- Final polish to ensure human-crafted appearance

## Available Commands

While in GodMode mode, you can use these specific commands:

- `/godmode analyze [description]` - Deep dive into requirements
- `/godmode design [type]` - Generate design systems (landing page, e-commerce, portfolio, etc.)
- `/godmode components [query]` - Search and retrieve specific ReactBits components
- `/godmode animate [element]` - Add specialized animations to elements
- `/godmode video [placement]` - Strategically embed video content
- `/godmode optimize` - Performance and accessibility optimization
- `/godmode export` - Generate final code package

## Example Usage

```
/godmode Create a modern SaaS landing page for a project management tool targeting enterprise clients, with smooth animations, embedded product demo video, and professional enterprise aesthetic
```

This will trigger the GodMode workflow to:
1. Analyze SaaS landing page requirements for enterprise audience
2. Select professional color palette and typography
3. Choose appropriate ReactBits components (navbars, feature cards, CTA buttons)
4. Integrate smooth animations and micro-interactions
5. Embed video player for product demo
6. Ensure responsive design across devices
7. Optimize for performance and accessibility
8. Deliver production-ready code that looks hand-crafted by senior developers

## Best Practices

To get the most out of GodMode:
1. Be specific about your website's purpose and target audience
2. Mention any brand guidelines or existing assets
3. Specify preferred technologies if you have requirements
4. Indicate desired level of animation (subtle to bold)
5. Note any video content you want to incorporate
6. Define your performance priorities

The system will intelligently balance all these factors to create a cohesive, professional website that meets your exact specifications while maintaining the highest standards of modern web design.
