# GodMode Skill

A senior-level website design orchestration skill that combines ReactBits components, UI/UX Pro Max design systems, ultracode workflows, and all available design skills to create professional, modern websites.

## Installation

The GodMode skill is installed by placing this directory in your Claude skills folder:
`~/.claude/skills/godmode-skill/`

## Usage

Once installed, you can invoke GodMode by:

1. Simply mentioning "godmode" in your conversation with Claude Code
2. Using explicit commands like `/godmode [your website description]`
3. Asking for website design assistance with specific requirements

## Features

- Access to 135+ animated React components via ReactBits MCP server
- 84 UI styles, 161 color palettes, 73 font pairings from UI/UX Pro Max
- Multi-agent orchestration through ultracode workflows
- Responsive, accessible, and performance-optimized designs
- Seamless video integration and multimedia support
- Output designed to appear human-crafted, not AI-generated

## Example

```
godmode Create a portfolio website for a freelance designer with interactive case studies, smooth scroll animations, and embedded video showreel
```

## Requirements

- Claude Code with ultracode/workflows enabled
- ReactBits MCP server installed and configured
- Optional: UI/UX Pro Max skill for enhanced design capabilities

## Files

- `skill.json` - Skill metadata and configuration
- `CLAUDE.md` - Detailed usage instructions and capabilities

## Notes

This skill acts as an orchestration layer that intelligently coordinates various design and development tools to produce senior-level website outcomes. It doesn't generate code directly but guides the AI through a comprehensive design process leveraging all available resources.
